# Adwings Cinematic Site

This workspace now contains a one-page Next.js concept site for Adwings with:

- Tailwind CSS styling
- Framer Motion reveal transitions
- A sticky founder section with layered cards
- Glassmorphism service boxes
- Hover-preview portfolio cards
- Animated performance counters

## Run locally

1. Install dependencies with `npm install`
2. Start the dev server with `npm run dev`

## Replace placeholders

- Founder portrait: `public/placeholders/ashujit-portrait.svg`
- Founder shadow image: `public/placeholders/founder-shadow.svg`
- Project stills: `public/placeholders/`
- Hero video: `public/media/hero-shooting-glimpse.mp4`
- Portfolio preview videos:
  - `public/media/ashu-services-preview.mp4`
  - `public/media/ashu-shooting-glimpse.mp4`

If the video files are not present yet, the page still renders and the still-image portfolio cards remain visible.
